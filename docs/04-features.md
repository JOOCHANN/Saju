# 04. 기능 명세 (Feature Specification)

## Phase 1 — MVP

### F1. 오늘의 무료 운세

**설명:** 로그인 없이 즉시 접근 가능한 일일 운세 콘텐츠

**입력값:**
- 12띠 선택 (쥐, 소, 호랑이, ...)
- (선택) 별자리 선택

**출력값:**
- 종합운, 애정운, 직장운, 금전운 (별점 + 한줄 요약)
- 오늘의 한마디 (AI 생성 or 큐레이션)
- 행운의 색상/숫자/방향

**기술 요건:**
- 하루 1회 생성 후 캐싱 (Redis)
- SEO를 위해 SSG/ISR로 렌더링 (Next.js)
- 자정 기준 갱신

---

### F2. 사주 기본 분석

**설명:** 생년월일/시간 입력 → AI가 사주 원국 해석

**입력값:**
- 양력/음력 구분
- 생년월일 (YYYY-MM-DD)
- 출생 시간 (HH:00, "모름" 선택 가능)
- 성별

**처리 과정:**
1. 입력값 → 사주 계산 엔진 (천간/지지/오행 계산)
2. 계산 결과 + 프롬프트 → Claude API 호출
3. AI 해석 결과 반환

**출력값:**
- 사주 원국 표 (년/월/일/시 × 천간/지지)
- 오행 분포 차트
- AI 해석 텍스트
  - 기본 성격 및 성향
  - 강점과 약점
  - 인생 키워드 5개
  - 올해/내년 흐름 한줄 요약

**기술 요건:**
- 사주 계산 라이브러리 직접 구현 또는 검증된 오픈소스 활용
- Claude API 응답 스트리밍 (타이핑 효과)
- 결과는 DB에 저장 (로그인 시)

---

### F3. 회원 인증 (Auth)

**회원가입:**
- 이메일 + 비밀번호
- 이메일 인증 (발송 후 클릭)
- 소셜 로그인: 카카오 OAuth, 구글 OAuth

**로그인:**
- 이메일/비밀번호
- 소셜 로그인

**보안:**
- bcrypt 비밀번호 해싱
- JWT (Access Token 15분 + Refresh Token 7일)
- Refresh Token Rotation

---

### F4. 마이페이지 / 보관함

**기능:**
- 저장된 사주 분석 결과 목록
- 분석 결과 상세 보기 (재확인)
- 내 기본 사주 정보 등록 (미리 저장해두면 재입력 불필요)
- 계정 설정 (비밀번호 변경, 탈퇴)

---

## Phase 2 — 수익화

### F5. 궁합 분석 (유료)

**입력:** 나 + 상대방 생년월일/시간/성별
**출력:**
- 종합 궁합 점수 (0~100)
- 항목별 궁합 (성격/애정/재물/건강)
- AI 상세 해석 + 조언

**가격:** 3,900원 (건당) 또는 크레딧 사용

---

### F6. 대운 분석 (유료)

**입력:** 사주 기본 정보
**출력:**
- 10년 단위 대운 흐름 표
- 현재 대운 AI 해석
- 앞으로 5년 운의 흐름과 전략

**가격:** 4,900원 (건당)

---

### F7. 연도별 운세 (유료)

**입력:** 사주 기본 정보 + 조회 연도
**출력:**
- 해당 연도 전반 운세
- 월별 주요 포인트
- 주의할 시기 / 유리한 시기

**가격:** 2,900원 (건당)

---

### F8. 결제 시스템

**결제 수단:**
- 카드 결제 (Toss Payments)
- 카카오페이

**결제 방식:**
- 건당 결제 (Phase 2)
- 크레딧 충전 방식 (Phase 2)
- 구독 (Phase 3)

**기술 요건:**
- Toss Payments SDK 연동
- 결제 Webhook 처리
- 결제 내역 DB 저장
- 환불 정책 구현
