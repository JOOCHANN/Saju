# 03. 사용자 흐름도 (User Flows)

## 핵심 사용자 여정 요약

```
[첫 방문자]
    │
    ▼
[홈 화면]
    ├── 오늘의 무료 운세 → 결과 보기 → (공유) → (회원가입 유도)
    │
    └── 사주 분석 시작
            │
            ▼
       [생년월일/시간 입력]
            │
            ▼
       [로그인/회원가입 요청] ← 비로그인 시 이 단계에서 요청
            │
            ▼
       [AI 사주 분석 결과]
            │
            ├── 보관함 저장
            ├── 공유 (카카오/링크)
            └── [프리미엄 기능 유도] → 결제 → 상세 결과
```

---

## Flow 1: 오늘의 무료 운세

```
홈 → "오늘의 운세" 탭 클릭
    → 띠(12지신) 또는 별자리 선택
    → 오늘 날짜 운세 카드 표시
        ├── 종합운 / 애정운 / 직장운 / 금전운
        └── [내 사주로 더 자세히 보기] CTA → Flow 2로 연결
```

**특징:**
- 로그인 불필요
- 매일 자정 갱신 (캐시 활용)
- 공유 버튼 제공 (카카오톡, 링크 복사)

---

## Flow 2: 사주 기본 분석

```
홈 또는 CTA 클릭
    → "사주 분석" 페이지
    → 정보 입력 폼
        ├── 양력/음력 선택
        ├── 생년월일 (달력 피커)
        ├── 출생 시간 (시간 선택 / 모름 선택 가능)
        └── 성별
    → [분석하기] 클릭
    → 비로그인 상태면 → 간편 로그인/회원가입 팝업
        └── "나중에 하기"로도 진행 가능 (결과는 세션에 임시 저장)
    → 로딩 (AI 분석 중... 애니메이션)
    → 결과 페이지
        ├── 사주 원국 (四柱) 표시
        ├── AI 해석 (종합 성격/성향/인생 키워드)
        ├── 연도별 흐름 요약 (올해/내년)
        └── [더 보기] → 유료 서비스 (Phase 2)
```

---

## Flow 3: 회원가입 / 로그인

```
가입 유도 팝업 또는 직접 접근
    → 소셜 로그인 (카카오, 구글)
    OR 이메일 회원가입
        → 이메일 + 비밀번호
        → 이메일 인증
    → 가입 완료
    → 이전 페이지로 복귀 (분석 결과 자동 저장)
```

---

## Flow 4: 마이페이지 / 보관함

```
로그인 상태 → 마이페이지
    ├── 저장된 사주 분석 목록
    ├── 내 정보 관리 (기본 사주 정보 등록)
    └── 구매 내역 (Phase 2)
```

---

## Flow 5: 궁합 분석 (Phase 2)

```
"궁합" 탭
    → 내 정보 + 상대방 정보 입력
    → [궁합 보기] → 결제 또는 크레딧 사용
    → AI 궁합 분석 결과
        ├── 종합 궁합 점수
        ├── 성격 궁합 / 애정 궁합 / 재물 궁합
        └── AI 해석 텍스트
```

## 화면 목록 (Screen Inventory)

### Phase 1
| 화면 | 경로 | 비고 |
|------|------|------|
| 홈 | `/` | 서비스 진입점 |

| 로그인 | `/login` | |
| 회원가입 | `/register` | |
| 마이페이지 | `/mypage` | 로그인 필요 |
| 개인정보 처리방침 | `/privacy` | |
| 이용약관 | `/terms` | |

## 모바일 네비게이션 구조

```
[하단 탭 바]
  홈 | 운세 | 사주 | 보관함 | 마이페이지
```

- 하단 고정 탭 바 (모바일 우선)
- 탭은 5개 이하로 유지
- Phase 2에서 "더보기" 탭으로 확장 가능
