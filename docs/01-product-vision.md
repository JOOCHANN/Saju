# 01. 서비스 비전 & 목표

## 서비스 이름 (가칭)
**Saju** (한국어 브랜드명은 추후 결정 — 예: 사주랩, 사주나, 내사주 등)

---

## 서비스 비전

> "AI가 해석해주는 나의 사주 — 언제 어디서나, 쉽고 정확하게"

한국 전통 사주 명리학을 AI로 해석하여, 복잡한 전문 지식 없이도
누구나 자신의 사주를 이해하고 삶의 방향을 찾을 수 있도록 돕는 서비스

---

## 핵심 가치 제안 (Value Proposition)

| 구분 | 내용 |
|------|------|
| **접근성** | 무료 콘텐츠로 진입 장벽 제거 (오늘의 운세는 항상 무료) |
| **AI 해석** | Claude AI가 사주 원리를 사람이 읽기 쉬운 언어로 해석 |
| **개인화** | 생년월일/출생시간 기반 나만의 분석 |
| **신뢰성** | 개인정보 보안 설계를 전면에 내세워 신뢰 구축 |
| **확장성** | 무료 → 유료 자연스러운 전환 구조 |

---

## 목표 사용자

- **주 타겟**: 20~40대 한국어 사용 여성 (사주/운세 콘텐츠 주 소비층)
- **부 타겟**: 인생의 전환점을 앞둔 모든 연령대 (이직, 결혼, 이사 등)
- **접근 채널**: 모바일 검색 (구글/네이버), SNS 바이럴, 직접 URL 접근

---

## 경쟁 차별화

| 항목 | 기존 서비스 | 우리 서비스 |
|------|------------|------------|
| 해석 방식 | 고정 텍스트 템플릿 | Claude AI 기반 맥락적 해석 |
| 진입 방식 | 유료 결제 먼저 | 무료 콘텐츠 → 자연스러운 유료 전환 |
| 개인정보 | 불투명한 데이터 처리 | 투명한 데이터 최소 수집 정책 |
| UX | 복잡한 메뉴 구조 | 모바일 우선, 단순한 흐름 |

## MVP 범위 (Phase 1)

MVP는 "핵심 사용자 루프"를 검증하는 것이 목표입니다.

### 포함할 기능
- [ ] 오늘의 무료 운세 (띠/별자리 기반, 비로그인 접근 가능)
- [ ] 사주 기본 분석 (생년월일 + 출생시간 입력 → AI 분석 결과)
- [ ] 회원가입 / 로그인 (이메일 + 소셜 로그인)
- [ ] 내 사주 저장 (마이페이지 — 이전 분석 결과 보관)

### MVP에서 제외 (Phase 2+)
- 결제 / 프리미엄 기능
- 궁합, 대운, 택일, 연도별 운세
- AI 채팅 상담

### MVP 성공 지표
- 월간 활성 사용자(MAU) 500명 달성
- 무료 운세 → 사주 분석 전환율 20% 이상
- 회원가입 전환율 15% 이상
