# 02. 사용자 페르소나

## 페르소나 1 — 김지연 (주 타겟)

| 항목 | 내용 |
|------|------|
| **나이** | 28세 |
| **직업** | 직장인 (마케터) |
| **성별** | 여성 |
| **접근 방식** | 스마트폰으로 점심시간에 접속 |

### 니즈
- "오늘 중요한 미팅이 있는데, 오늘 운세가 어떤지 빠르게 확인하고 싶어요"
- "연애 운이나 직장 운을 가볍게 보고 싶어요"
- "복잡한 사주 용어 설명보다 내 상황에 맞는 쉬운 해석이 필요해요"

### 행동 패턴
- 앱보다 모바일 웹 선호 (설치 귀찮음)
- 결과를 카카오톡/인스타로 친구에게 공유
- 무료로 먼저 체험하고 만족하면 소액 결제

### 핵심 여정
`오늘의 운세 무료 확인` → `사주 기본 분석 시도` → `회원가입` → `결과 저장/공유`

## 페르소나 2 — 박민수 (부 타겟)

| 항목 | 내용 |
|------|------|
| **나이** | 35세 |
| **직업** | 스타트업 창업자 |
| **성별** | 남성 |
| **접근 방식** | 중요한 결정 전 심층 분석을 원함 |

### 니즈
- "이직 타이밍이 맞는지, 창업 시점이 언제가 좋은지 알고 싶어요"
- "대운 흐름과 올해 운세를 종합적으로 보고 싶어요"
- "신뢰할 수 있는 서비스인지 개인정보 처리 방식이 궁금해요"

### 행동 패턴
- 심층 분석 결과에 기꺼이 결제 의향
- PC에서도 접속 (출장, 사무실)
- 결과를 직접 저장/캡처해서 참고용으로 활용

### 핵심 여정
`사주 분석 검색` → `사주 기본 분석` → `대운/연도별 운세 유료 결제`

## 페르소나 3 — 이수현 (잠재 타겟)

| 항목 | 내용 |
|------|------|
| **나이** | 42세 |
| **직업** | 주부 |
| **성별** | 여성 |
| **접근 방식** | 가족 궁합, 자녀 사주에 관심 |

### 니즈
- "자녀의 사주와 나의 궁합이 어떤지, 교육 방향을 어떻게 잡을지"
- "결혼기념일, 이사 날짜 등 좋은 날 고르고 싶어요 (택일)"

### 핵심 여정
`궁합 분석` → `택일 서비스` → `구독 모델 가입`

## 공통 UX 요구사항

| 요구 | 설명 |
|------|------|
| **빠른 진입** | 회원가입 없이도 핵심 가치(무료 운세) 즉시 경험 |
| **쉬운 입력** | 생년월일 입력 UX를 최대한 간단하게 (달력 피커 + 시간 선택) |
| **읽기 쉬운 결과** | 한자/전문용어 최소화, AI가 풀어서 설명 |
| **공유 가능** | 결과를 이미지/링크로 쉽게 공유 |
| **신뢰 신호** | 개인정보 처리 방침을 눈에 띄는 곳에 배치 |
